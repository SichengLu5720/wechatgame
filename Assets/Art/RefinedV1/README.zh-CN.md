# Sky Islands 精致美术资产 V1

状态：DRAFT，美术待用户评审。适用于本工程的 Unity 6000.0.26f1 Built-in 渲染管线。

本包是实际的三维网格、材质、贴图、预制体和展示场景。六色人物对应红、蓝、绿、黄、紫、黑，共用 Pilgrim 网格，各自使用 Cloth 材质。平台、楼梯、桥梁、背景塔楼分别独立；没有替换原有游戏关卡或修改通行规则。

## 材质与性能

每个预制体一个 MeshRenderer、一个材质槽。共享网格、共享材质启用 GPU Instancing。几何构建器只在编辑器导出时执行，运行时没有生成逻辑。彩色部位通过网格第二 UV 通道标记，原有渐变显色和道具变暗可分别使用 `_RevealTint`、`_PropDim`。

IvoryStone-v1.png 是 AI 生成的象牙石材原始贴图，Unity 导入上限 512；SurfaceGrain.png 是 256 像素可重复细节纹理。两者开启 mipmap 和压缩；不是每个人独占贴图。浅色材质使用石材贴图，人物使用布面细节和模型褶皱。

`RefinedSurface.shader` 支持主光源阴影及可选高度雾。正式小游戏接入时，需沿用设备质量档位，实测阴影预算；展示场景的灯光和静态模型截图不代表微信真机帧率。当前没有进行微信打包、上传或真机性能验收。

## 预览及接入

打开 `Scenes/AssetReview.unity` 查看真实模型组合。单独拖入 Prefabs 中任意预制体即可查看。素材是完整独立资产；现有 Play.cmd 仍然运行 v7.13.2，不会自动替换游戏内容。

源生成器在 `Assets/Editor/RefinedArt`。工程根目录运行 `scripts/export_refined_art.py` 会在隔离副本导出并渲染，不会自动覆盖正式玩法模型。OBJ 用于几何交换；完整顶点色、布料颜色通道和材质请使用 Unity 资产包。

## 人工美术审核项

- ART-01：六色小屏辨识，黑色角色和隐藏人物的区别。
- ART-02：兜帽开口、围巾厚度、褶皱、鞋和饰件比例是否符合概念图。
- ART-03：象牙石材、青玉角饰、金色嵌件的精细度与整体风格。
- ART-04：平台规格、等高桥的缓拱、楼梯接口与台面衔接。
- ART-05：竖屏中远景塔楼的对比度和高度雾。

这些项目全部待审；自动网格检查和截图检查不构成人工美术批准。
